# patterns/app/

App/product UI patterns. Data tables, command palettes, multi-step forms, empty states, side nav — anything used by **users who do tasks** rather than visitors who read content.

See [`../README.md`](../README.md) for the pattern file format and contribution rules.

For marketing patterns (heroes, content sections, narratives), see [`../marketing/`](../marketing/).

This folder starts empty. It fills as you build real projects.
