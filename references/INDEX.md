# Reference Vault: INDEX

> Curated catalog of sites worth studying. Organized by aesthetic vocabulary, not industry. Each entry has a one-line note on *why* it works.
>
> **How to add:** When you find a site worth keeping, add a line here under the right category. Optionally create a full analysis at `references/[slug].md` using the structure in [`../analyzer/extract-prompt.md`](../analyzer/extract-prompt.md). Commit message: `references: add [domain]`.

---

## Editorial / Type-led

Sites where typography is the design and content is the show.

- [pentagram.com](https://www.pentagram.com): Studio standard. Massive type, restrained color, project-as-essay structure.
- [manual.is](https://manual.is): Manual studio. Editorial feel, mixed type sizes inline, considered grid breaks.
- [are.na](https://www.are.na): Quiet, type-driven, near-zero ornament. Reads like a print object.
- [readymag.com](https://readymag.com): Editorial showcase. Long-form structure, expressive type, heavy art direction.
- [robinrendle.com](https://www.robinrendle.com): Personal site as editorial object. Long-form is the point.

## Swiss / Minimal / Product

Restrained, grid-led, professional. The "Linear school".

- [linear.app](https://linear.app): Influence-defining product marketing. Subtle motion, dense info architecture, restrained color.
- [stripe.com](https://stripe.com): The reference for product marketing at scale. Type system, color usage, code samples integration.
- [vercel.com](https://vercel.com): Heavy on hover/scroll motion, dark-mode-first aesthetic, geometric.
- [resend.com](https://resend.com): Quietly excellent. Bold type, deliberate spacing, restrained palette.
- [arc.net](https://arc.net): Browser company. Marketing site that pioneered "soft pastel + serif" for product.
- [raycast.com](https://raycast.com): Product launcher. Tight gradients, opinionated type, command-palette-as-design.

## Motion / Interactive

Sites where motion is the primary expressive medium.

- [resn.co.nz](https://resn.co.nz): Studio. WebGL, custom cursors, motion-as-content.
- [activetheory.net](https://activetheory.net): Studio. Heavy WebGL, audio-reactive, theatrical.
- [locomotive.ca](https://locomotive.ca): Studio. Smooth scroll defined here. Motion-led storytelling.
- [hellomonday.com](https://www.hellomonday.com): Studio. Cinematic case study showcases.
- [hassan.lol](https://hassan.lol): Personal site. Custom motion, idiosyncratic interactions.

## Brutalist / Expressive

Sites that break grid rules deliberately. Loud, opinionated, unmistakable.

- [bureau-cool.com](https://www.bureau-cool.com): Studio. Brutalist defaults, mixed type, rejection of polish.
- [yotam-ott.com](https://yotam-ott.com): Personal portfolio. Type-as-content, dense.
- [areweanonymous.com](https://areweanonymous.com): Internet-poetic, expressive, wrong on purpose.
- [moooi.com](https://www.moooi.com): Furniture brand pushing the boundary of "shop site as art object".

## Studio / Agency

Reference for how to present work and capability.

- [area17.com](https://area17.com): Studio. Restrained, work-as-content, strong case studies.
- [hej.studio](https://hej.studio): Small studio. Distinct visual identity, strong type.
- [toy.studio](https://www.toy.studio): Studio. Maximalist, expressive, color-heavy.
- [unseen.co](https://www.unseen.co): Studio. Quiet sophistication, image-led case studies.

## Modern SaaS done well

The narrow band of SaaS marketing that escapes slop.

- [pitch.com](https://pitch.com): Presentation tool. Strong type, real motion.
- [framer.com](https://www.framer.com): Framer's own marketing site. Showcases what their tool can do; very polished.
- [retool.com](https://retool.com): Engineering tool. Dense, type-led, real-feeling.
- [notion.com](https://www.notion.com): Polished, restrained, illustration-led.
- [supabase.com](https://supabase.com): Strong dark-mode aesthetic, interactive demos.
- [openstatus.dev](https://www.openstatus.dev): Engineer-mono voice. Whole UI in `ui-monospace` + Inter fallback, compressed display tier (h1 = 30px), outlined-rect status pills. Reach for this when the project's voice is "rendered output, not marketing."

## App / Product UI

References for **app interfaces** (logged-in product surfaces, dashboards, tools), not their marketing pages. Used in app mode when references are appropriate. Many require an account to inspect deeply; screenshots and case studies are sometimes the best access.

- [linear.app](https://linear.app): The actual app (post-login). Issue tracker that defined modern app UI restraint. Command palette, keyboard-first.
- [stripe.com/dashboard](https://stripe.com/dashboard): Payment dashboard. Reference for data tables, settings architecture, financial UI clarity.
- [notion.so](https://www.notion.so): Knowledge tool. Reference for nested content, contextual menus, inline editing.
- [vercel.com/dashboard](https://vercel.com/dashboard): Deployment dashboard. Reference for build/log surfaces, project list, real-time status.
- [retool.com](https://retool.com): Internal-tool builder. Reference for dense data UIs, configurable layouts.
- [pitch.com](https://pitch.com): In-app presentation tool. Reference for collaborative editing, slide canvas.
- [plausible.io](https://plausible.io): Analytics dashboard (live demo available without signup). Reference for clean data display, restrained color.
- [cal.com](https://cal.com): Booking tool. Reference for multi-step forms, calendar widgets, public-facing app surfaces.
- [readymag.com/editor](https://readymag.com): In-app editor. Reference for canvas-based editing, side panels.
- [arc.net](https://arc.net): Browser. Reference for sidebar navigation, command palette, native-feeling web app.
- [things.app](https://culturedcode.com/things/): Native to-do app. Reference for restraint, type-driven app aesthetic.
- [pocketcasts.com](https://pocketcasts.com): Podcast app. Reference for media-app patterns.

## How to use this vault

When the user gives you 1-3 reference URLs at intake, those are the project's primary references. This vault is for:

- Finding *additional* references when the user's set is thin or one-note
- Showing the user examples when they say "something like X but more Y"
- Studying patterns that recur across multiple references (a structural move shared by Stripe, Linear, and Vercel is signal worth borrowing)
- Reminding yourself what good looks like when defaults start creeping in

If you analyze a site from this list deeply, save the analysis at `references/[slug].md`. Otherwise the link is enough; visit fresh each time.
